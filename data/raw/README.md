# Raw source data

이 폴더는 외부에서 받은 원천 데이터의 보관 위치입니다. 이번 정리에서는 기존 루트 파일을 내용 변경 없이 이동합니다.

새 원천 데이터를 추가하기 전에 다음을 확인하세요.

- 출처와 수집일
- 재배포·상업적 이용이 가능한 라이선스
- 개인정보·연락처·비밀정보 포함 여부
- 파일 크기와 재생성 가능 여부
- 무결성 확인용 체크섬

개인정보나 연락처가 포함된 원천 데이터는 공개 저장소에 커밋하지 않습니다. 재생성 가능한 대용량 결과물은 외부 저장소에 두고, 저장소에는 생성 스크립트와 다운로드 절차만 기록하는 방식을 우선합니다.

폴더 이동은 기존 Git 기록의 용량을 줄이지 않습니다. 저장소 용량을 줄이려면 별도의 이력 정리 작업과 영향 검토가 필요합니다.
