## 구글시트 반영 방법
이 환경에는 Google Sheets **수정(update) API/커넥터가 없음**(LESSONS L008).
기존 파일에 탭을 직접 쓰지 않고, 아래 중 하나로 반영한다.

1. **권장**: 구글 드라이브에서 `파일 → 가져오기 → 업로드`로 xlsx 업로드 후, 기존 v3 시트를 대체(또는 탭 복사)
2. 기존 시트에 탭을 수동으로 만들고, 각 CSV를 탭별로 붙여넣기
3. Zapier Google Sheets 등으로 행 단위 동기화
