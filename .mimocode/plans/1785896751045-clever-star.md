# solve: 로그인 세션만료 무한반복 + 로그인 느림

## 1. 원인분석 (증거 확보 완료)

### 근본 원인: refresh_token 일회용 블랙리스트 + 미회전

| 레이어 | 파일:라인 | 문제 |
|--------|----------|------|
| **서버** | `services/p1-export-fit-api/app/routers/auth.py:81` | `add_to_blacklist(decoded["jti"])` — refresh_token 사용 즉시 블랙리스트 등록 (일회용) |
| **서버** | `services/p1-export-fit-api/app/routers/auth.py:82` | `return {"access_token": ...}` — **새 refresh_token 미반환** |
| **클라이언트** | `apps/frontend-react/src/lib/api.js:25` | `localStorage.setItem('access_token', ...)` — **refresh_token 미저장** |

### 무한반복 흐름

```
1. 로그인 → access_token + refresh_token 저장
2. access_token 만료 → 인터셉터가 refresh 시도
3. 서버: refresh_token 블랙리스트 등록 + 새 access_token만 반환 (82번줄)
4. 클라이언트: 새 access_token만 저장, 죽은 refresh_token 그대로 (25번줄)
5. 새 access_token 만료 → 같은 죽은 refresh_token으로 재시도
6. 서버: 블랙리스트에 있으므로 거부 → 401
7. onRefreshFailed → 토큰 삭제 → auth:logout → 로그인 화면
8. 사용자 재로그인 → 1번으로 복귀 → 무한루프
```

### 로그인 느림 원인

- 로그인 직후 `syncBalanceFromServer()` + `api.get('/v1/auth/me')` 병렬 호출
- 둘 다 같은 `api` 인스턴스 사용 → 토큰이 유효해도 Vercel proxy 경유 시 응답 지연
- `AuthPage` 마운트 시 `/v1/demo/summary` 호출도 추가 지연 요소

## 2. 해결방안

**선택: 서버 refresh_token 회전 + 클라이언트 저장 (최소 변경, 보안 강화)**

- 서버: refresh 엔드포인트에서 새 refresh_token도 함께 반환
- 클라이언트: refresh 성공 시 refresh_token도 저장
- 기존 블랙리스트 로직은 유지 (보안 유지)

## 3. 해결실행 (수정 범위)

### 파일 1: `services/p1-export-fit-api/app/routers/auth.py` (라인 77~82)

```python
# 변경 전:
@router.post("/refresh")
def refresh(payload: Dict[str, Any] = Body(...)):
    token = str(payload.get("refresh_token", ""))
    decoded = decode_refresh(token)
    add_to_blacklist(decoded["jti"])
    return {"access_token": create_access_token(decoded["sub"])}

# 변경 후:
@router.post("/refresh")
def refresh(payload: Dict[str, Any] = Body(...)):
    token = str(payload.get("refresh_token", ""))
    decoded = decode_refresh(token)
    add_to_blacklist(decoded["jti"])
    return {
        "access_token": create_access_token(decoded["sub"]),
        "refresh_token": create_refresh_token(decoded["sub"]),
    }
```

### 파일 2: `apps/frontend-react/src/lib/api.js` (라인 25~26)

```javascript
// 변경 전:
localStorage.setItem('access_token', data.access_token)
return data.access_token

// 변경 후:
localStorage.setItem('access_token', data.access_token)
if (data.refresh_token) localStorage.setItem('refresh_token', data.refresh_token)
return data.access_token
```
