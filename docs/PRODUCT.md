> 작성일: 2026-07-23 · 상태: 설계 확정(구현 전) · 상위 문서: `docs/ARCHITECTURE.md`(시스템 설계)

## 1. 벤치마크 결론

노크(knok)와 케이몬즈(Kmonds)는 별도 경쟁사가 아니라 **동일 사업자가 운영하는 하나의 수출사업 퍼널**이다: 노크 = 무료 노출·바이어 DB·캐럿 결제의 셀프서비스 진입층, 케이몬즈 = 아카데미·미팅지원·월 멤버십의 고관여 실행층.

벤치마크할 것은 바이어 명함 판매가 아니라 다음 4가지다:

1. **무료→소액→프로젝트→구독의 가격 사다리** (첫 결제 장벽 최소화)
2. **교육을 플랫폼 활성화 수단으로 쓰는 구조** (아카데미 = 유료 온보딩)
3. **투입시간이 아닌 결과 단위 상품** ("미팅 1회"처럼 산출물이 상품명)
4. **플랫폼+사람 하이브리드 운영** (초기 고객이 사는 것은 소프트웨어가 아니라 실행)

반대로 **적용 금지 4가지** — 연락처 직접 열람 판매, 대량 콜드메일(5,000~10,000건) 핵심상품화, 복잡한 포인트(캐럿) 전면 노출, 무조건적 미팅 보장 — 는 ARCHITECTURE.md의 핵심 제약(연락처 비노출·중개 발송·소진 통제)과 충돌하므로 배제한다.

### 1.1 경쟁사 핵심 사실 검증 (2026-07-23)

벤치마크 문서의 경쟁사 사실 주장을 사이트 원문 대조로 병렬 검증한 결과, **20건 전부 CONFIRMED**. 보정·유의사항 4건:

| 항목 | 확인 결과 | 유의 |
|---|---|---|
| 캐럿 단가·최소 충전 | 1캐럿 2,000원, 5만원부터 5만원 단위 충전 | — |
| 바이어 열람·터치업 | 열람 5캐럿(재열람 무료), 터치업 1차 10캐럿 | **2차 이상은 30캐럿(약 6만원)** — 후속접촉일수록 비싸지는 구조 |
| 세일즈팩 | 200캐럿(40만원 상당), 미팅 불성사 시 재주선 | MarketGate Managed 조건부 보증(§4)과 동형 |
| 콜드메일 | 5,000/10,000건 플랜, 고객 실사용 메일 계정으로 발송·회신 수신 | 플랜별 캐럿 가격은 페이지 미기재 |
| 브랜드 등록 | 100% 무료, MOQ·단가·인코텀즈·HS코드 등 B2B 정보 입력 | Export Passport 벤치마크 원형 |
| 아카데미 | 15시간, 300만원(**VAT 별도**), 툴킷 13종·캐럿·바이어 매칭·콜 1회·20명 정원 | 수출바우처 활용 안내 있음 — 정부지원 결제 경로 실재 |
| 멤버십 | 월 500만원(3·6개월 기준, **12개월은 월 450만원**), 월 4~6건 미팅, 3인 지원 | — |
| 운영주체 | knok·케이몬즈 동일 법인(사업자등록번호 348-81-02438 동일) 교차 확인 | "하나의 퍼널" 해석 확정 |
| 자체 실적 수치 | "10,000회+ 매칭, 2,000건+ 성사, 15,000+ 네트워크"는 자체 주장으로 게재 확인 | **사이트 내부에서도 수치 불일치**(미팅 10,300 vs 9,000회, 156 vs 103개국) — 분모 공개형 성과 카드(§8)의 차별화 근거 |

## 2. 상품 사다리 (고객 관점)

내부적으로 모든 상품은 ARCHITECTURE.md §7.4의 슬롯·크레딧 인벤토리로 환산되며, 빈도상한·배타성·컴플라이언스 게이트를 동일하게 통과한다.

| 단계 | 상품 | 핵심 산출물 | 가정 가격 |
|---|---|---|---:|
| 무료 | **Export Product Passport** | 수출여권·준비도 점수·적합국가 3개·BEP | 0원 |
| 체험 | Buyer Signal Check | 바이어 유형·국가·적합성 신호 3건 | 3.9만~9.9만원 |
| 진단 | Market Validation | 국가·규제 분석 + 검증 바이어 매칭 5개사 | 29만~49만원 |
| 실행 | Outreach Campaign | 검증 바이어 10개사 중개접촉 + 응답 리포트 | 99만~149만원 |
| 미팅 | Meeting Ready Pack | 미팅 준비·통역·회의록·후속조치 | 49만~79만원 |
| 교육 | Export Sprint (§5) | 4주 교육 + 수출자료 + 실제 캠페인 실행 | 99만~199만원 |
| 구독 | Growth Workspace | 월 매칭·발송·후속관리 + Deal Workspace | 월 69만~99만원 |
| 관리형 | Managed Export Desk | 전담 운영·미팅·견적관리 | 월 249만~399만원 |
| 기관형 | MarketGate Program | 지자체·기관 참여기업 10~50개사 통합관리 | 3,000만~1억원 |

체험~진단 상품에서도 **연락처 열람권은 제공하지 않는다** — 산출물은 매칭 근거와 중개접촉 권리다.

### 2.1 전환 퍼널

```text
콘텐츠·지원사업·무료 진단
  ↓  Export Passport 완성 (판매자 데이터 확보)
  ↓  Buyer Signal Check 구매 (첫 결제, 저위험)
  ↓  Outreach Campaign 실행 (긍정 응답·미팅 발생)
  ↓  Growth Workspace 구독 (Deal Workspace·후속관리)
  ↓  K-SURE 신용조사·보험·견적·샘플·계약 관리 (락인)
  ↓  국가·제품 확대 → Managed Desk 업셀
```

## 3. Export Product Passport (무료 진입 상품)

노크의 무료 브랜드 등록을 벤치마크하되, 목적을 "노출"이 아닌 **판매자 구조화 데이터 확보 + 활성화**로 재정의한다. 시스템 정의는 ARCHITECTURE.md §7.5.

| 구분 | 주요 필드 |
|---|---|
| 기업 | 기업명, 홈페이지, 설립연도, 수출국 |
| 제품 | 제품명, 카테고리, HS Code, 주요 특징 |
| 거래 | 공급단가, MOQ, 생산능력, 리드타임 |
| 조건 | 인코텀즈, 결제조건, 독점 가능 여부 |
| 인증 | 국가별 인증, 시험성적서, 유효기간 |
| 콘텐츠 | 영문 소개서, 이미지, 카탈로그 |
| 수출준비 | 샘플, 라벨, 물류, 통관 준비도 |

무료 산출물: 수출준비도 점수 / 적합국가 3개 / 적합 바이어 유형 / 누락자료 체크리스트 / 예상 BEP(기존 BEP 기능 재사용) / 공개 가능한 영문 제품 페이지.

사업 효과: `무료 진단 사용자 확보 → 판매자 데이터 축적 → 매칭 정밀도 향상 → 유료 전환` — CAC 절감과 데이터 플라이휠을 동시에 만든다.

## 4. 결과 단위 상품과 보증 조건

상품명은 투입시간("컨설팅 10시간")이 아니라 고객 결과("검증 바이어 10개사 캠페인")로 정의한다.

**보증 가능/불가 기준 (고정):**

| 보증 대상 | 적용 |
|---|---:|
| 바이어 기업 실재 | 가능 |
| 품목 적합성 검수 | 가능 |
| 발송 성공 (delivered) | 가능 |
| 무효 연락수단 교체 | 가능 |
| 약정한 수의 중개접촉 실행 | 가능 |
| 미팅 불성사 시 후보 교체 | 조건부 (Managed 상품 한정) |
| 긍정 응답 | 보장 곤란 — 실측 벤치마크만 제시 |
| 수출계약 | **보장 불가** |

표준 보증 문구:

> 검수기준을 충족한 바이어에게 정해진 횟수의 적법한 중개접촉을 실행하고, 무효·중복·접촉불가 바이어는 교체한다.

Managed 상품 한정 조건부 보증:

> 3개월 동안 적격 미팅이 1건도 발생하지 않을 경우, 다음 달 후보 매칭·접촉 서비스를 무상 연장한다.

무조건적 "미팅 보장"은 형식적 미팅 배정·저적합 바이어 대체·원가 상승을 유발하므로 금지.

## 5. Export Sprint (교육 = 유료 온보딩)

케이몬즈 아카데미 벤치마크. 별도 교육사업이 아니라 **플랫폼 활성화 프로그램**으로 설계한다.

| 항목 | 설계 |
|---|---|
| 기간 / 교육시간 | 4주 / 총 8~12시간 |
| 정원 | 8~15개사 |
| 가격 | 기업당 99만~199만원 (지원사업형 200만~300만원) |
| 포함 | 3개월 Growth Workspace + 실제 캠페인 1회 |

| 주차 | 교육·실행 | 플랫폼 산출물 |
|---|---|---|
| 1주 | 제품·기업 수출준비 진단 | Export Passport 완성 |
| 2주 | 국가·채널·바이어 전략 | Target Market 확정 |
| 3주 | 영문 제안·가격·거래조건 | Campaign Draft |
| 4주 | 중개발송·미팅 시뮬레이션 | 실제 캠페인 실행 |

케이몬즈(경험 기반 영업교육) 대비 차별점: 데이터 기반 국가선정, B/L·규제·전시회 신호, 바이어별 적합성 근거, 응답률 추적, K-SURE 연계, 종료 후 Deal Workspace 유지.

## 6. 구독 이원화 (자동화 vs 사람)

케이몬즈 월 500만원 풀패키지와 동일 인력서비스를 저가에 제공하려 하지 말고, 자동화 영역과 전문가 영역을 분리한다.

| 요금제 | 운영방식 | 가정 가격 |
|---|---|---:|
| Growth | 셀프서비스 + 자동화 | 월 49만~79만원 |
| Pro | 월 1회 전문가 검수 | 월 99만~149만원 |
| Managed Desk | 전담 매니저·미팅지원 | 월 249만~399만원 |
| Institution | 지자체·기관 다수 기업 통합관리 | 연 3,000만~1억원 |

초기 매출 메시지는 "AI 수출 플랫폼"이 아니라:

> 해외영업 담당자를 채용하지 않고도, 검증 바이어 선정부터 제안·응답·미팅 준비까지 실행하는 수출영업 운영서비스

| 구분 | 반영 전 | 반영 후 목표 |

| 첫 상품 | 캠페인 129만원 | 체험 9만원 → 캠페인 129만원 |
| 구독 전환율 | — | 30% (가정) |

## 8. UX 원칙

**첫 화면 메시지:**

> 귀사 제품을 지금 검토할 가능성이 높은 해외 바이어를 찾고, 연락처 노출 없이 제안부터 응답까지 관리하세요.

**대시보드 상단 (성과 퍼널):**

```text
이번 달 수출 파이프라인
신규 검증 바이어 12개사 → 중개접촉 9개사 → 긍정 응답 3개사 → 미팅 예정 2개사 → 견적 요청 1개사
```

**다음 액션 피드:** "싱가포르 바이어 MOQ 질문 답변", "미국 바이어 2개사 7일 후속발송", "긍정 응답 바이어 K-SURE 신용조사 검토" 같은 구체 행동 단위.

**크레딧은 내부 단위로만:** 내부 원장은 크레딧(중개발송 10C 등)으로 관리하되, 고객 화면에는 "신규 바이어 접촉 10개사 / 후속발송 20회 / 전문가 검수 2회"처럼 **행동 단위**로 표시한다. 노크 캐럿처럼 환산 계산을 고객에게 떠넘기지 않는다.

**성과 카드는 분모까지 공개:** 경쟁사의 자체 제시 실적(만 회 매칭 등)과 달리, `검수 30 → 발송가능 24 → 전달 22 → 응답 5 → 긍정 3 → 미팅 2 → 견적 1`처럼 정의·분모를 공개해 신뢰로 차별화한다.

## 9. 경쟁 포지셔닝

| | 노크 | 케이몬즈 | **MarketGate** |
|---|---|---|---|
| 한 줄 정의 | 전시회 바이어 정보를 열람하고 직접 접촉하는 플랫폼 | 사람·현장 경험으로 미팅과 수출영업을 대행하는 팀 | **신호로 바이어를 선별하고, 연락처 비노출로 접촉·응답·거래위험까지 추적하는 수출영업 운영 플랫폼** |
| 신뢰 근거 | 실물 명함 | 미팅·성사 사례(자체 수치) | 현재 구매신호(수입 이력·규제등록·활동) + 공개 분모 퍼널 |
| 연락처 | 구매자에게 공개 | 대행팀이 보유 | Vault 비노출 중개 |
| 발송 | 고객 계정 대량(5천~1만) | 수동 영업 | 10~50개사 고적합 중개발송 + 빈도상한 |
| 거래 이후 | — | 후속관리(사람) | Deal Workspace + K-SURE 신용조사·보험 연계 |

차별화 축 요약: DB 수량→신호 깊이 / 연락처 판매→비노출 중개 / 대량발송→제한적 고적합 발송 / 명함 보유→현재 구매의도 / 미팅 횟수→응답·견적·계약 퍼널 / 일회성 발굴→Deal Workspace / 수출영업 지원→수출영업+거래위험 관리.

경쟁사가 "바이어를 만나는 곳"이라면 MarketGate는 **"안전하게 거래를 진행하는 곳"**이다:

```text
긍정 응답 → 신용조사 필요도 판정 → K-SURE 신청 지원 → 위험등급 반영
```

## 10. 단계별 반영 과제 (ARCHITECTURE.md Phase와 정합)

**Phase 0 (컨시어지 + 최소 화면):**
- [ ] Export Product Passport 입력 화면 + 무료 수출준비도 결과
- [ ] 소액 체험상품 1종 (Buyer Signal Check 또는 Verified Match 3)
- [ ] 바이어별 매칭 근거 카드 (신호·출처·검수 결과 표시)
- [ ] 캠페인 보증·교체 조건 문구 확정 (§4)
- [ ] 성과 퍼널 대시보드 (분모 공개형)
- [ ] 고객사례 작성 템플릿

**Phase 1:**
- [ ] Export Sprint (교육+캠페인 결합) / Meeting Ready Pack
- [ ] 자동 후속발송 / Deal Workspace / 구독 전환 오퍼
- [ ] K-SURE 거래안전 워크플로 (ARCHITECTURE.md §8)

**Phase 2:**
- [ ] Managed Export Desk / 기관형(Institution) 통합관리
- [ ] 익명 업종 벤치마크 (품목군 평균 응답률 등)
- [ ] 바이어 RFQ 인바운드 / CRM·견적·샘플·계약 연동

**최우선 과제는 노크의 무료 노출 모방이 아니라 Export Product Passport로의 전환**이다: 무료로 판매자 데이터를 구조화하고, 소액 검증상품→캠페인→구독으로 연결하면 데이터 확보·CAC 절감·LTV 증대를 동시에 달성한다.
