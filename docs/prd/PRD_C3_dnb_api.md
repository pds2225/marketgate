# PRD: C3 - D&B 외부 기업조회 연계

## 1. 목적
MarketGate 해외기업 기본검증 결과에서 D&B 공식 D-U-N-S 조회 페이지로 연결한다.

초기 MVP에서는 D&B의 재무·신용정보를 자동 조회하지 않으며, 법인등록 기본검증과 유료 신용조사를 명확히 분리한다.

## 2. 현재 MVP 구현 범위
- D&B 공식 D-U-N-S Lookup 외부 링크 제공
- 바이어 상세의 기본검증 카드에서 새 창으로 연결
- D-U-N-S 존재 여부는 사용자가 외부 공식 페이지에서 확인
- MarketGate 화면에는 자동 신용등급·위험점수 미표시

## 3. 현재 MVP 제외 범위
- `DNB_APP_KEY`, `DNB_SECRET_KEY` 환경변수 추가
- D&B API 인증 클라이언트
- 기업명·국가 기반 DUNS 자동 검색
- 신용등급·부도위험·연매출·직원수 자동 조회
- D&B 결과 캐싱
- B2 PDF 자동 연동
- D&B 웹페이지 스크래핑

실제 API 연동은 상품계약, 호출비용, 저장·표시·재이용 권한이 확인된 후 별도 작업으로 진행한다.

## 4. 화면 요구사항
바이어 상세의 `법인등록 기본검증` 영역에 다음 버튼을 제공한다.

```text
D-U-N-S 조회
```

버튼 설명:

```text
D&B 공식 페이지에서 기업의 D-U-N-S Number 등록 여부를 확인합니다.
D-U-N-S Number 존재만으로 신용도나 지급능력이 확인되는 것은 아닙니다.
```

## 5. 데이터 정책
- MarketGate DB에는 D&B 조회결과를 자동 저장하지 않음
- 사용자가 별도 확인한 D-U-N-S Number를 향후 입력할 수 있는 필드는 선택사항으로 유지
- D-U-N-S 존재 여부를 `신용 우수`, `안전한 바이어`로 변환하지 않음
- D&B 유료 보고서의 내용을 계약 없이 재표시하지 않음

## 6. 예외처리
- 외부 링크 설정 누락: 버튼 비활성화 + `외부 조회 링크 준비 중` 표시
- 새 창 차단: 링크 복사 가능 처리
- D&B 서비스 장애: MarketGate 기본검증 결과 유지
- 조회결과 없음: `자료 내 확인 불가`로 표시

## 7. 테스트 기준
- 외부 링크가 새 창으로 열림
- `noopener noreferrer` 적용
- 링크 누락 시 화면 오류 없음
- D-U-N-S 미확인 상태에서 번호를 임의 생성하지 않음
- 신용등급·risk score·재무정보가 임의 표시되지 않음
