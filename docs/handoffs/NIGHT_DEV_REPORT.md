### 전에는 안 되던 게 이제 됩니다 (실사용 효과)
1. **데모 화면**: 없는 가짜파일(404)만 부르던 깨진 데모 → 실제 바이어 3.6만 건 집계를 로그인 없이 보여주는 진짜 쇼케이스(연락처는 마스킹).
2. **문의 버튼**: 일반요금제가 누르면 "실패"만 뜨던 것 → "Advanced 요금제 기능입니다, 업그레이드하세요" 안내.
3. **바이어 검색 실패**: 두 번째 검색이 실패하면 이전 결과가 남아 착각하던 것 → 상황별 안내 + "다시 시도" 버튼, 0건이면 키워드 안내.
4. **예측 결과**: 데이터 없는 나라가 "0점"처럼 보이던 것 → "데이터 없음" 솔직 표시 + 저신뢰도 안내("0점은 결측이지 실제 0 아님").
5. **결제 후 화면**: 결제 끝내고 돌아와도 확인 화면이 안 떠 불안하던 것(실은 화면이 도달 불가) → 결제 완료/취소 확인 화면이 제대로 뜸.
6. **결제 버튼**: 응답이 비면 빈 404로 튕기고 "처리중"에 영구 고착되던 것 → 친절한 안내 + 버튼 복구.
7. **로그인 오류**: 서버 장애인데 "오류" 한마디라 비번 탓인 줄 알고 재시도→계정잠금 되던 것 → "서버 연결 문제"로 구분 안내(헛고생·잠금 방지).
8. **수출 주문서**: "공급자(내 회사/담당자)" 칸이 항상 빈칸이던 것 → 입력란 추가로 주문서에 자동 기재.
9. **세션 만료**: 작업 중 말없이 로그인 화면으로 튕기던 것 → "세션 만료, 다시 로그인" 안내 배너.
10. **바이어 연락처**: 연락처 없는 바이어도 "확인됨" 도장 + 죽은 전화/홈페이지 링크가 뜨던 것 → "정보 없음/미확인" 솔직 표시.

### 사람이 결정/확인할 항목 (코드 아님 — 제가 안 건드림)
- **배포 설정**: `payment.py`의 `BASE_URL` 환경변수가 프로덕션에선 배포 도메인(Vercel)을 가리켜야 함(기본값 localhost). 결제 리다이렉트 정상화에 필요 — 배포 콘솔에서 확인 권장.
- **회원가입(bcrypt)**: Python 3.13 환경에선 bcrypt 비호환으로 가입 테스트가 깨짐(3.14는 정상). 배포 파이썬 버전에 따라 실가입이 막힐 수 있어 점검 권장. (의존성 변경이라 자동 수정 안 함.)
- 검색/예측으로 생성된 테스트 계정·런타임데이터(`data/users.json`·`subscriptions.json`)는 커밋 안 함(로컬에만 존재).

4. 🔴 비화장품(쌀·휴대폰·완성차) 빈 결과 — "데이터 없음"이 "바이어 없음"으로 오인.
5. 🟠 추천국↔반환 바이어국 불일치(중국 추천인데 미국 바이어), 무고지 폴백.
