# MarketGate 프론트엔드 설계 문서 v3.0
# — 수출 거래 마켓플레이스 UI/UX 설계 (사업계획서 반영)

> **프로젝트:** MarketGate (AI 기반 글로벌 수출 거래 마켓플레이스)
> **버전:** v3.0 — 사용자 요청 반영
> **목표:** 품목 검색 → 바이어 검증 → 발송 → 완료 4단계 플로우
> **수익 모델:** 4중 BM — BM1 구독+크레딧 / BM2 제휴수수료 / BM3 중개수수료 / BM4 데이터/온프레미스
> **상태:** 설계 단계 (미반영)
> **작성일:** 2026-05-03

---

## 1. Executive Summary

### 1.1 핵심 변경사항 (v2 → v3)

| 변경 | v2 | v3 |
|------|-----|-----|
| **단계 수** | 5단계 | **4단계** |
| **Step 1** | 카테고리 카드 선택 | **자연어 입력 → HS 추천 → MOQ + 인증 필터** |
| **반도체** | 카테고리 포함 | **제거** |
| **수익성분석** | Step 2 필수 | **부가기능(선택) — 별도 영역** |
| **MOQ/인증 필터** | 없음 | **Step 1에 추가** |
| **인콰이어리 발송** | 단순 버튼 | **실제 SMTP 서버 연동 + 큐 트래킹** |
| **주문완료** | 별도 Step 5 | **Step 4에 통합** |
| **수익 모델** | 크레딧 단일 | **4중 BM (구독+크레딧/제휴/중개/데이터)** |

### 1.2 4가지 수익 모델 (BM)

| BM | 유형 | 대상 | UI 반영 위치 |
|---|---|---|---|
| **BM1** | 구독 + 크레딧 충전 | B2C/B2B | 상단 크레딧 표시 + 구독 플랜 페이지 |
| **BM2** | 타 서비스 제휴 수수료 | B2B | 파트너 마켓플레이스 — 관세/물류/법률 연계 |
| **BM3** | 직접 계약 중개 수수료 | B2B | 계약 완료 시 중개 수수료 3~5% 표시 |
| **BM4** | 데이터 판매 / 온프레미스 | 대기업/기관 | 엔터프라이즈 전용 메뉴 — 온프레미스 구축 견적 |

### 1.2 크레딧 과금 구조

| 단계 | 서비스 | 크레딧 | 원화 |
|------|--------|--------|------|
| Step 1 | 품목 검색 (Market Scan) | 0 | ₩0 |
| Step 2 | Buyer Fit Lite | 20 | ₩20,000 |
| Step 2 | Buyer Fit Pro | 50 | ₩50,000 |
| Step 4 | 인콰이어리 발송 | 5 | ₩5,000 |
| Step 4 | 응답 수신 | 10 | ₩10,000 |
| — | 수익성 분석 (선택) | 15 | ₩15,000 |
| **합계** | **Pro + 발송 + 응답** | **65** | **₩65,000** |

**핵심 설계:**
- **자연어 → HS 코드:** 품목명 입력 → AI가 관련 HS 코드 3~5개 추천 → 사용자 선택
- **MOQ 콤보박스:** 6단계 범위 선택 (100개 이하 ~ 10,000개 이상)
- **보유인증 체크박스:** FDA/ISO/Halal/CPNP/비건 — 선택 시 실시간 프리뷰
- **검색 전 입력 항목:** 위 3가지가 전부 — 이후 `[검색 시작]` 버튼
- **수익성 분석:** 부가기능으로 분리 — 별도 expandable 영역, 기본 플로우에서 제외
- **반도체 카테고리:** 제거 — K-뷰티/건강식품/K-패션만
- **경쟁사 비교 프리뷰:** 검색 전 "코트라 대비 95% 시간 절감" 툴팁 노출
