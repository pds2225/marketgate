# Thomasnet · Kompass EasyBusiness 벤치마크 → MarketGate 적용

> 목적: 두 글로벌 B2B 플랫폼을 벤치마크해 **"따라할 부분"** 을 도출하고, MarketGate(HS코드/제품 → 수출 대상국 추천 + 바이어 매칭 엔진)에 **반영할 개발계획**으로 연결한다.
> 작성: 2026-06-24. 근거: Thomasnet 8차원 자동 웹리서치(워크플로우) + 사용자 Kompass 리서치. 상세 개발계획은 [`.omc/plans/benchmark-thomasnet-kompass.md`](../../.omc/plans/benchmark-thomasnet-kompass.md)(ralplan 합의 APPROVE, rev4).
> **합법성 원칙:** 두 서비스의 문구·분류체계·점수공식·디자인은 복제하지 않는다. 구조·흐름만 참고하고 MarketGate 자체 로직·문구로 재구성한다.

---

## 1. 한눈에 — 무엇을 따라하나

| | Thomasnet | Kompass EasyBusiness | MarketGate가 가져갈 핵심 |
|---|---|---|---|
| 정체성 | 북미 산업재 **공급사 디스커버리** 디렉토리 | 글로벌 B2B **리드 발굴 + AI 영업비서** | 수출 **대상국 추천 + 바이어 매칭 + 액션화** |
| 핵심 통찰 | 검색→평가→연결→견적을 **한 화면에서 액션**으로 | "데이터 제공"이 아니라 **보는 정보를 즉시 액션으로 전환** | 점수/매칭에서 끝내지 말고 **"그래서 뭘 하라"** 까지 |
| 무료 진입 | 익명 검색 + 1분 무료계정 | 확장프로그램 무료 설치 | 무료 Market Scan → 유료 전환 |

**결론:** MarketGate의 기존 PRD 로드맵(A1~E1)은 이미 Kompass 벤치마크와 강하게 겹친다(Buyer Fit·수익성 시뮬·컨택추적·바이어검증·구독/크레딧 BM). 벤치마크의 진짜 가치는 ① 기존 로드맵이 옳다는 **검증**과 ② 아직 없는 **갭 3개(수출준비도·AI 영업메일·액션플랜)** 식별이다.

## 2. Thomasnet 벤치마크 (자동 웹리서치 결과)

| 영역 | 확인된 사실 | MarketGate 시사점 |
|---|---|---|
| 서비스 구조 | Search(공급사 검색) → Evaluate(프로필·최대5개 비교) → Connect(Shortlist·다중 RFI) → Request Quotes(통합견적·CAD 즉시견적) 4기둥 | "검색→비교→연락→견적" 단계 동선을 수출 맥락으로 |
| 검색 | Smart Search(부품·역량·소재·인증 이해) + 좌측 패싯 필터, 관련도 기본정렬(회사규모·매출·설립연도 재정렬) | 바이어 검색에 **패싯 필터 + 다중 정렬** 도입 |
| 필터 패싯 | 회사유형(제조/유통/커스텀/서비스), **품질인증 ~80종**(ISO9001·AS9100·IATF·ISO13485·NADCAP·FDA·ITAR), **다양성/소유 20+종**, 지역+ZIP 반경, 인증배지(Verified) | 자사 택소노미로 재구성한 **Faceted Buyer Filter**(F1) |
| 공급사 프로필 | 회사이력·유형·역량·장비·제품라인·취급브랜드·인증·뉴스·이미지/영상·다운로드 자산 | Buyer Fit Pro 프로필 필드 풍부화(B2) |
| 즉시견적/CAD | 10M+ 2D/3D CAD, Xometry 기반 Instant Quote(STEP 등 업로드→가격·납기·**DFM 제조성 피드백**, 15+공정) | (수출 맥락엔 직접 해당 적음 — 보류) |
| 연결 | Shortlist 최대5 비교, 1건 RFI로 **최대 20개 공급사** 동시 발송, **CSV export**(자사 조달시스템 업로드) | 바이어 Shortlist·다중 인콰이어리·내보내기 |
| 규모(마케팅 카피) | 500,000+ 공급사, 67,000+ 카테고리, 6M+ 제품 | 규모 표현은 자사 실데이터 기준으로만 |
| 합법성 | `www.thomasnet.com` 루트는 **봇 차단(HTTP 403)**, 약관상 스크래핑/데이터마이닝 금지 | **대량 크롤링 금지**, 구조 벤치마크 + 제한적 표본만 |

## 3. Kompass EasyBusiness 벤치마크 (사용자 리서치)

- **AI Sales Assistant:** 기업요약·이상고객군(ICP)·경쟁사·시장트렌드·조직도/의사결정자·**이메일 3종 + LinkedIn 초대 자동생성**·Gmail/Outlook 발송·Pain Point·인물 포트레이트.
- **데이터/검색:** 60+ 고급필터, 지도·차트·테이블, 파이프라인 관리, 커스텀 리포트.
- **BM:** 구독(Free/Starter/Pro/Consultant/Enterprise) + 크레딧 과금 + (성과수수료 가능).
- **핵심 통찰:** Analyze → Target → Engage → Close. 즉 **발굴 후 즉시 액션(메일·파이프라인)** 으로 연결하는 것이 차별점.

## 5. 확정 개발계획 (ralplan 합의 APPROVE)

**채택안: "조합형 액션 레이어"** — 기존 출력(국가점수·바이어매치·수익성·제재·신뢰도)을 **조합**해 신규 산출물 3개를 비파괴(additive)로 추가. 외부 API·결제·PII·웹수집 0 → **야간 무인 실행 적격**.

| 순서 | 증분 | 내용 | 야간 무인 |
|---|---|---|---|
| 1 | **B6 AI Sales Letter** | 바이어 정보로 개인화한 영문 콜드메일+제안 초안(발송·저장 없음) | ✅ 1순위(순수 단일함수) |
| 2 | **B5 Export Readiness** | predict 결과를 0~100 수출준비도 + 차원별(시장/바이어/마진/제재) 판정 | ✅ 교차검증 테스트 green 뒤 |
| 3 | **B7 Action Plan** | 결정론적 30/60/90일 액션 리스트 | ✅ B5 뒤 |

**핵심 안전장치(계획에 못박음):**
- **비파괴:** 기존 응답 키 불변(스냅샷 회귀 테스트). 신규는 새 라우터 모듈 + models.py Optional 필드만.
- **단일 진실 출처:** 제재=compliance.py, 신뢰도=confidence.py, 국가점수=scoring.py 결과만 소비, **재계산·재감점 금지**.
- **야간 안전 증명:** service 순수함수를 테스트로 직접 호출(인증 HTTP 미경유) + 런타임 스파이(파일쓰기/네트워크 호출 시 테스트 실패).
- **롤백:** 격리 복사본에서 실행, 실패 증분은 커밋 미생성(main 무영향).
- 검증: `python -m pytest services/p1-export-fit-api -q`.

**합의 과정에서 잡은 실제 버그:** 수익률 `margin_rate=(원가합/landed)-1`이 구조상 **항상 ≤ 0**이라, 처음 설계한 margin 임계표는 모든 실거래를 fail로 바닥냈을 것 → simulation의 `profit_grade`(적자/손익분기/보통) 카테고리 소비로 교체. **코드 한 줄 쓰기 전 계획 단계에서 차단.**

**사람 승인 게이트(야간 제외):** B3 MOQ(실데이터에 moq 필드 없음), B4 컨택추적(PII), C1~C3 외부 API(키·PII), S1 지원사업(데이터셋 없음), 브라우저 확장(ToS).
